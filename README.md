# PvP Visuals (Fabric, MC 1.21.11)

Косметический клиентский мод: target ESP (круг/ромб/призрак вокруг цели)
и партиклы при попадании. Клавиша `]` переключает стиль ESP.

## Сборка через GitHub Actions (без своего компьютера)

1. Создай новый **приватный** репозиторий на GitHub.
2. Загрузи в него все файлы из этого архива (сохраняя структуру папок,
   включая скрытую папку `.github`).
3. Открой вкладку **Actions** в репозитории — сборка запустится
   автоматически после пуша (или нажми "Run workflow" вручную).
4. Дождись зелёной галочки (обычно 2–5 минут).
5. Зайди в завершённый запуск → внизу раздел **Artifacts** →
   скачай `pvp-visuals-mod.zip` — внутри будет готовый `.jar`.
6. Установи Fabric Loader 1.21.11 + Fabric API 0.141.6+1.21.11,
   закинь скачанный `.jar` в `.minecraft/mods`.

## Локальная сборка (если есть ПК)

```
./gradlew build
```
Готовый jar: `build/libs/pvp-visuals-1.0.0.jar`
